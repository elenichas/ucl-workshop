# References

Put images here: screenshots of websites, magazine spreads, exhibition catalogues, packaging, buildings — anything whose feel you want to bring into your configurator.

Then, for example:

```text
Read resources/references/my-reference.png and describe its layout,
typography, colour and tone in DESIGN.md terms. Don't change any code.
```

Name files clearly (`gallery-catalogue.png`, not `Screenshot 2026-11-03 at 10.42.png`) and only use images you're allowed to use.
